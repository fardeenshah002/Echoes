# ECHOES - Next-Gen Audio Streaming Platform

ECHOES is a modern, high-performance web audio streaming application built with a dark glassmorphic UI, real-time song discovery, audio visualization, and dynamic audio controls.

## 🚀 Features
- 🎵 **Global Song Search**: Real-time track search powered by external audio APIs.
- 🎛️ **Audio Spectrum Visualizer**: Dynamic HTML5 Canvas audio wave visualization.
- 🌙 **Aesthetic Dark Mode**: Glassmorphism UI built with Tailwind CSS and FontAwesome icons.
- 📱 **Responsive Design**: Clean player dock and responsive layout for desktop and mobile devices.

## 🛠️ Built With
- HTML5 / CSS3 / JavaScript (ES6+)
- Tailwind CSS
- FontAwesome Icons
- Web Audio Canvas Rendering

## ⚡ Deployment
This project is fully static and ready for instant deployment on GitHub Pages!
